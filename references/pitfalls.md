# 踩坑记录（首版 2026-11-20）

| 现象 | 原因 | 解决 |
|---|---|---|
| 特写镜头里看不到高尔基体 | 结构整个在剖切面以下，被蛋白地毯盖住 | 把细胞器中心放在 z≈0 到 0.5，让它跨过剖切面 |
| 高尔基体像一块橙色实心板 | 用 SphereGeometry 帽子压扁后，侧面看是一整块 | 改成同心球帽上铺小球，帽与帽间距 0.42，边缘的小球放大 1.6 倍 |
| 剖开后上半部有糖蛋白头部悬空 | 头部在 uCutR 以外，没被切掉，但下面的柄被切了 | uCutR 要比最外层附着物还大，或者把附着物整体判断 |
| 第一版近景太近，蛋白像巨大的球 | 相机偏移只有 5–7 | 近景偏移加到 9–12，能看到层次 |
| 伪足镜头只看到一根管子 | 锚点放在伪足尖端，相机在细胞外面 | 锚点改在伪足 30% 长度处，hero 伪足强制水平 |
| 成片只有 1080 宽，不是 2160 | CDP 截图的 clip.scale 写成了 1 | 应该写 `scale: DPR` |
| 白底发灰 | 让 three 对白色背景做了 ACES 色调映射 | 只对场景颜色手动做 ACES，背景在显示空间里直接混合 |
| 病毒受体镜头里很杂乱 | 宿主膜离病毒太近，刺突和受体互相穿插 | 宿主膜放到 z=-22 |
| μm 显示成 MM | `.tag` 的 CSS 写了 text-transform:uppercase | 单位元素单独设成 none |
| 404 报错 | 浏览器请求 favicon | 加上 `<link rel="icon" href="data:,">` |
| 第一帧空白或文字字体不对 | 字体和着色器还没就绪就开始截图 | 等 `window.__ready` 和 `document.fonts.ready` |

## v2（分泌蛋白课本测试，2026-11-20）
| 现象 | 原因 | 解决 |
|---|---|---|
| 高尔基体旁一块平行四边形黑斑，多次修改都没去掉 | GTAO 屏幕空间 AO 在剖切边缘和深坑处判断失误；normal 调试图本身也显示异常 | 弃用 GTAO，改成按邻居数量逐颗烘焙 AO（`bakeAO`），零伪影，而且不额外耗时 |
| 线粒体被剖开后是空心的，透过去能看到底层 | 外膜用了透明材质 | 外膜和内膜都改成不透明，剖开后能看到双层膜和嵴 |
| 线粒体插进高尔基体 | 只检查了线粒体中心点是否在空地，没检查两端 | 检查中心点和两端共 5 个点 |
| 近景里蛋白像一个个大球 | 相机离得太近 | 分子步骤的相机距离保持在 4–6 |
| 抗锯齿不够 | 实时渲染没有 MSAA | 用 `--dpr 2` 渲染，再 `--scale` 缩回目标尺寸 |

## v2 第二、三轮审查的教训（过程动画）
| 审查发现 | 解决 |
|---|---|
| 标记不守恒：1 条链变出 14 个团块、中途消失、凭空出现 | 标记分子做成固定的一批（12 个），用 `where(pt, t)` 逐段首尾相接，任何时刻每个分子都有位置 |
| 出芽或胞吐时膜不动，囊泡只是缩小 | 膜改为动态贴片：开孔半径 rn = √(rv² − hc²)，孔缘内翻成 Ω 形；囊泡只画在膜的一侧 |
| 内容物短暂裸露在胞质中 | 进入内质网以后，分子位置只允许在腔内或囊泡内插值 |
| 信号肽写进字幕但画面里没有 | 信号肽单独着色，穿过通道（翻译转运复合体环）后被切除、淡出 |
| 回顾"3 min"时画面上还留着已分泌的标记 | 回顾开始前先清场，让主线标记淡出 |
| 关键事件被字幕挡住 | 讲解版用 `setViewOffset` 把画面主体推到右上方 |
| 辉光过曝，看不清一团标记 | bloom 强度 0.32、阈值 0.95；发光强度 1.4 |
