# 准确性协议（怎么保证没有错误信息）

## 三条红线
1. **不编数据**：画面上的数字、时间、比例都必须有出处（课本节、论文 DOI、权威综述）。没有出处就不上屏。
   不做假仪表盘、假计数器、随时间乱跳的读数。
2. **不编过程**：动画里每个事件都必须对应真实的生物学事件，顺序、方向、所在区室都要对。
   - 机制没有定论的，只画"位置随时间变化"，不画具体机制。例如高尔基体内的转运，只画标记从顺面推进到反面，不画成"传送带"。
   - 不画不存在的东西，例如 ATP 光束、能量射线。
3. **不夸大**：字幕用课本或综述原有的措辞，不加"惊人地""瞬间"这类修饰。比例和时间的处理在画面上明示（非真实比例 · 时间已压缩）。

## 流程
```
事实表（每行有出处）
  → 禁止画面清单（这个主题的常见错误）
  → 审查①：独立子智能体审事实表 + 场景设计
  → 搭场景、出样张
  → 审查②：独立子智能体（教授 + 美术总监）审样张、字幕、过程代码
  → 改完所有"错误/误导"级问题 → 复审（只审改动部分） → 出片
```

## 审查子智能体的写法
- 只给原始材料：脚本、场景代码、样张路径、事实表。**不要给自己的结论**，避免它附和。
- 要求它按固定表格输出：位置 | 问题 | 严重度（错误/误导/可改进）| 正确做法 | 依据。
- 要求它对"能否直接用于教学"给出明确结论。
- 拿到结果后逐条核对。审查意见本身也可能出错，存疑的条目要去查原始文献，不能直接照改。

## 常用权威来源
- 课本：人教版普通高中《生物学》必修1《分子与细胞》（2019）等。字幕优先用课本原句。
- 教科书：Alberts《Molecular Biology of the Cell》、Lodish《Molecular Cell Biology》。
- 原始论文：例如分泌途径用 Jamieson & Palade, J Cell Biol 1967；Palade, Science 1975（诺贝尔奖演讲）。
- 结构数据：PDB / EMDB。需要真实分子形态时，改走 Mol*、ChimeraX 或 Molecular Nodes（见 techniques.md）。
