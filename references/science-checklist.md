# 科学核查清单

标注里每一个数字、每一句功能描述，都要能在课本、综述或论文里找到出处。拿不准的就不写数字，只写定性的描述。

## 常用尺度（示意片里的用法）
| 对象 | 典型尺度 | 写法建议 |
|---|---|---|
| 动物细胞 | 直径 10–30 μm | "约 10–30 μm" |
| 质膜 | 厚 7–8 nm（不同教材写 7–10 nm） | "厚约 7–8 nm" |
| 细胞核 | 直径 5–10 μm | |
| 线粒体 | 长 1–4 μm，宽约 0.5–1 μm | 不同细胞差异大 |
| 核糖体 | 真核 80S，约 25–30 nm | |
| 核孔复合体 | 外径约 100–120 nm | |
| 丝状伪足 | 直径 0.1–0.3 μm，长可达数十 μm | 伸缩速度别写死，写"可快速伸出与回缩" |
| 冠状病毒（SARS-CoV-2） | 直径约 60–140 nm（冷冻电镜测得均值约 90 nm） | |
| 刺突蛋白 S | 三聚体，伸出长约 20–25 nm，每个颗粒约 25–40 个 | |
| SARS-CoV-2 基因组 | 单股正链 RNA，约 3 万个碱基（29.9 kb） | |
| IgG 抗体 | Y 形，约 10–15 nm | |
| 大肠杆菌 | 约 1×2 μm | |

## 常见错误
- 把"示意比例"讲成"真实比例"。程序化场景里的蛋白都被放大了很多倍，画面上必须写"非真实比例"。
- 颜色是教学配色。真实细胞基本透明，不要写"线粒体是橙色的"这类话。
- 粗面内质网和核膜外层是连通的，这句可以写；高尔基体和内质网不直接连通，靠囊泡运输。
- 病毒的包膜来自宿主细胞的膜（冠状病毒在 ERGIC 处出芽，不是从质膜），这一点不要写错。
- 中和抗体的作用是阻断结合，不是"杀死病毒"。
