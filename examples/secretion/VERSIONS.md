# secretion 案例：版本与提示词记录

## v8（当前视频，2026-11-21）
- **引擎**：skill `bio-viz-film` 的 `template/site2`，场景 `scene-acinar.js`（v3 真实比例版），本仓库标签 `v3.1`。
- **成片**：
  - 讲解版：1920×1080，60fps，87 秒（`story=secretion`，`layout=lecture`，`look=academic`）
  - 炫片竖版：1080×1920，60fps，37 秒（`story=secretion-reel` → `layout=reel`，`look=vivid`，`fx=channels`，`density=2.5`）
  - 1080p 原片在 Release `v3.1`，仓库里放的是 720p 压缩版。
- **录制命令**：
  ```
  node tools/record.mjs site2 out/lecture.mp4 --size 1920x1080 --dpr 2 --scale 1920x1080 --fps 60
  node tools/record.mjs site2 out/reel.mp4 --size 1080x1920 --dpr 2 --scale 1080x1920 --fps 60 --query story=secretion-reel
  ```
- **耗时**：在一台消费级 GPU 上，讲解版约 34 分钟，炫片约 16 分钟。用 `--draft` 出预览档大约只要 1/8 时间。
