# 细胞器形态核查 + 与推特参考视频对比（分泌蛋白 v2）

## 一、细胞器形态逐项核查

结论：**结构关系都对**，可以用于课本层级的教学；但**形状是示意性的，有几处比真实情况简化或偏规整**，做论文或高校层级的内容前应改进。

| 结构 | 现在的做法 | 判断 | 不足 / 可改进 |
|---|---|---|---|
| 细胞整体 | 椭球，核在基底、高尔基体在核上方、分泌颗粒在顶端、顶端有微绒毛 | ✅ 极性分布对 | ⚠ 真实腺泡细胞是**锥形或楔形**，许多细胞围成腺泡，顶端朝向中央腔。我们只画了一个孤立的椭球细胞，也没有画出腺泡腔 |
| 细胞核 | 双层核膜 + 核孔 + 外周异染色质 + 核仁 | ✅ | 核孔做成了贴在膜上的圆环，没有画出内外核膜在核孔处融合 |
| 粗面内质网 | 三层同心的扁囊，每层两层膜夹一个腔，核糖体只在胞质侧，与外核膜相连 | ✅ 关系对 | ⚠ **太规整**，像同心球壳。真实的是平行排列、有起伏的扁囊，边缘相互连通。与核膜相连的"颈"内部腔隙没有真正连通（拓扑简化） |
| 核糖体 | 粉色小球，主角核糖体分大小两个亚基 | ✅ | 胞质中游离核糖体和多聚核糖体偏多偏大，抢眼 |
| 信号肽 / 通道 | 青色信号肽穿过膜上的通道环，之后被切除 | ✅ 课本以上的拓展 | 通道（易位子）只是示意的圆环 |
| 高尔基体 | 6 层弓形扁囊，边缘膨大，有穿孔，顺面朝内质网、反面朝顶端 | ✅ 方向对 | 反面高尔基网络（TGN）的管网结构没有画；扁囊厚度一致，看起来偏整齐 |
| 运输囊泡 / 分泌颗粒 | 囊泡从膜上鼓出、断开；分泌颗粒是珠状膜包着致密内容物 | ✅ | ⚠ **大小比例失真**：真实的运输囊泡约 60–80 nm，酶原颗粒约 1 μm，相差 10 倍以上；我们只差约 2 倍（画面写了"非真实比例"，但仍可能误导） |
| 线粒体 | 双层膜，嵴在内膜里面，剖开可见 | ✅ | 嵴做成了一片片均匀的圆盘，真实的嵴更不规则；也没有画基质颗粒 |
| 微管 | 从高尔基区伸向顶端 | ✅ 可接受 | 只是装饰性的轨道，没有表现囊泡沿微管被马达蛋白运送 |
| 细胞质 | 灰色小颗粒 + 多聚核糖体 | ✅ | 密度远低于真实的拥挤程度，与 Goodsell 风格的分子拥挤图差距大 |

## 二、与推特上一条爆款细胞视频对比

| 维度 | 推特视频 | 我们 v2 | 谁更好 |

## 三、比不过的地方，以及怎么补（按优先级）
1. **密度和质感**：细胞质分子数量提高 3–5 倍，用多种形状（不只是小球）表示蛋白；加一点体积雾或景深层次。
2. **开场冲击**：前 5 秒加一个"由外到内"的连续推镜，可选配一个基于事实的转场（例如用剖切面推进来代替换色）。
3. **短视频版**：从 83 秒的片子里剪一条 30 秒以内的"精华版"，竖版 1080×1920，配合 `notes` 或 `dashboard` 版式。
4. **形态升级**：内质网改成起伏、连通的扁囊；加上 TGN 管网；腺泡细胞改成楔形，加上相邻细胞和腺泡腔；囊泡和颗粒的大小拉开差距。
5. **渲染速度**：83 秒成片约需 20 分钟，可以加一个预览档（低分辨率、30fps）用于快速确认。
