# 审查记录：突触网页版（第 1 轮独立审查，2026-11-21）

审查人：独立子智能体（神经科学教授 + 科普片美术总监），看了 10 张样张、story、scene、layout、事实表。

## 结论
结构尺寸、过程顺序、传递方向、离子进入侧、星形胶质摄取、页面计数的标注都正确；改完 1 个错误 + 5 个误导项即可发布。

## 发现与处理
| 级别 | 问题 | 处理 |
|---|---|---|
| ERROR | 模型时钟把清除放在 5–10 ms，与字幕"约 1 ms"矛盾；谷氨酸曲线 10 ms 才降完 | 时钟改为 1.0→3.6 ms；扩散与清除加速窗口提前到 30–36 s，约 2 ms 模型时间降到 10% 以下；字幕改"1–2 ms" |
| MISLEADING | "放慢约 1 万倍"不对（实际 800–40 万倍不等） | 时钟重排为近似线性，页脚改"~4,000–15,000×（非线性），回收进一步压缩" |
| MISLEADING | "LIVE / live section"像真实显微镜 | 改为"3D MODEL / 3D model section" |
| MISLEADING | 动作电位曲线落后于画面；Ca²⁺ 在峰值前进入 | 到达镜头内跑完上升支；Ca²⁺ 窗口从峰值（~0.33 ms）开始 |
| MISLEADING | 星形胶质、AMPA、转运体都是粉色；Ca²⁺ 和 AP 环同为青色 | 星形胶质改灰蓝、转运体深石板蓝、AP 环改电光黄 |
| MISLEADING | 第 8 步措辞像"衣被小窝被装填"；网格蛋白外壳穿过质膜 | 改写字幕与标注（内吞 → 新小泡由 vGLUT 装填 → 另一个小泡锚定，注明"经典途径之一"）；外壳裁剪面内移到膜内侧 |
